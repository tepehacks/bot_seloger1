Rechercher tous les XPath invalides du projet.

2. GESTION DES ERREURS UNICODE
━━━━━━━━━━━━━━━━━━━━━━

Au démarrage du programme :

```python
import sys

try:
    sys.stdout.reconfigure(encoding="utf-8")
    sys.stderr.reconfigure(encoding="utf-8")
except:
    pass
```

Créer :

```python
def safe_log(text):
    try:
        return str(text)
    except:
        return repr(text)
```

Tous les logger.info(), logger.warning() et logger.error()
affichant du texte provenant du site doivent utiliser safe_log().

Le logger ne doit jamais provoquer une exception.
